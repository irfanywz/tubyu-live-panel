# Prompt untuk AI baru (salin dan tempel di chat baru)

Kamu melanjutkan proyek **Tubyu Live Panel** dari chat sebelumnya. Jangan membaca seluruh proyek dari awal.

Langkah wajib:
1. Baca `AI_MEMORY/AI_HANDOFF.md` terlebih dahulu.
2. Baca `AI_MEMORY/AI_INSTRUCTIONS.md` dan ikuti aturannya. Khususnya: **jangan menjalankan tes atau pengecekan di sistem**; pemilik yang menguji.
3. Baca `AI_MEMORY/CURRENT_TASK.md` dan `AI_MEMORY/CODE_MAP.md` jika relevan dengan tugas.
4. Periksa source code hanya pada file yang relevan (gunakan pencarian nama fungsi), dan cocokkan dengan dokumentasi.
5. Jangan mengulang pekerjaan yang sudah selesai. Lanjutkan dari "Langkah berikutnya" di `CURRENT_TASK.md` kecuali pemilik meminta lain.
6. Jika ada keputusan yang ingin diubah, periksa `DECISIONS.md` dan tanyakan dulu ke pemilik.
7. Setelah bekerja, perbarui `AI_HANDOFF.md` dan `CURRENT_TASK.md`, serta dokumen lain yang terdampak.
